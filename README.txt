Supabase project is already configured in index.html.
Supabase database has organization/profile/branch security and realtime sync enabled.

To install as an app on Android:
1. Host this folder on HTTPS (Vercel/GitHub Pages).
2. Open the HTTPS URL in Chrome.
3. Chrome menu -> Add to Home screen / Install app.

Cloud login:
- Use the existing Supabase Auth account.
- After login, Admin can create additional users from User Management.
